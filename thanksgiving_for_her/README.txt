THANKSGIVING WEBSITE FOR HER

Open index.html in a browser to preview the website.
The assets folder contains 6 photos and 9 videos copied from your uploads.

To publish it:
1. Upload the entire 'thanksgiving_for_her' folder to a static website host (for example, Netlify Drop or GitHub Pages).
2. Keep the assets folder beside index.html.
3. Do not upload only index.html; the photos and videos are stored in assets.

To personalize:
- Edit the letter text in index.html.
- Change the page title or footer if you want.
- Replace or add files in assets, keeping the same filenames or updating the image/video paths in index.html.
